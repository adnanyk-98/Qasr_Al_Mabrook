# BUG TRACKER

This file is the active, structured bug tracker for the repository. Follow the Documentation Rules at the bottom of this file before editing.

No currently confirmed open bugs.

---

**Documentation Rules**

- Never invent bugs.
- Never mark an issue fixed without verification.
- Never delete historical fixes.
- Update an existing issue instead of creating duplicates.
- Reference related `BUG-`, `KI-`, and `FIX-` IDs.
- Record the actual root cause, not merely the symptom.
- Record the exact verification performed.
- Keep production incidents separate from development-only issues.

Guidance for new bug reports:

- Use stable IDs: `BUG-001`, `BUG-002`, ...
- Populate all required fields in the template at the top of this file.
- Attach links to logs, failing tests, or reproduction screenshots where applicable.
- If a bug is environment-specific (local vs staging vs prod) mark Environment accordingly.
